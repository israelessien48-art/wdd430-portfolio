# WDD430 Portfolio

A personal portfolio built with Next.js, TypeScript, and Tailwind CSS for the WDD430 Week 1 assignment.

## Live Website

[Visit My Portfolio](https://wdd430-portfolio-roan-one.vercel.app/)

## Features

- Home page with project cards and GitHub links
- About page with a reusable SkillCard component
- API endpoint at `/api/hello`

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

## Custom Component

`SkillCard.tsx` is a reusable component that displays a title and a list of skills in a styled card.
